# 📊 Process Support Helpdesk

Process Support Helpdesk is a real-time case management and monitoring dashboard designed to track and manage field support helpdesk activities efficiently.

---

## 🚀 Live Demo

🔗 **Demo Link:** https://gauravaswal98.github.io/Process-Helpdesk-Panel/

---

## 🚀 Features

- 📌 Real-time Case Distribution Report
- 📞 Multi-Source Case Tracking (Call, Chat, Email)
- 📊 Resolution & Pending Task Monitoring
- 📈 Dashboard Analytics & Summary Cards
- 🔍 Search & Filter Records
- 📥 Data Upload & Download Functionality
- 📑 Grand Total & Percentage Calculation
- 🎨 Modern Responsive UI

---

## 🖥️ Dashboard Overview

The application provides:

- Resolution Percentage
- Top Source Identification
- Pending Task Status
- Case Distribution by Source
- Open, Resolved & Closed Case Tracking
- Downloadable Reports
